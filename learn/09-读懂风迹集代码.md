## 1. 阅读代码的"黄金步骤"

看到一段陌生代码时,按这个顺序读:

```
1. 找入口(从 main.tsx / server.js 开始)
   ↓
2. 看 import/require(它依赖什么)
   ↓
3. 看函数签名(类型定义告诉你输入输出)
   ↓
4. 跟数据流(请求/响应从哪里来,到哪里去)
   ↓
5. 看工具函数(单行能看懂的直接读)
   ↓
6. 看业务逻辑(条件、循环、错误处理)
```

**核心原则**:**不要逐行读,而是按"层级"一层层进**。

## 3. 跟一个完整请求,理解全流程

**我们跟一个具体例子:用户登录后,创建一个博客**

### Step 1:打开浏览器,进入登录页

**React 启动**:
```
main.tsx 渲染根
   → <App /> 加载所有路由
   → /login 匹配到 <Login /> (lazy + Suspense 包着)
   → Login 组件渲染表单
```

**Login 组件** [frontend/src/pages/Login/Login.tsx]:
```tsx
function Login() {
  const navigate = useNavigate()
  const { login: setAuth } = useAuthStore()    // 从全局拿到登录函数

  async function handleSubmit({ usernameOrEmail, password }) {
    // 1. 调用 services/auth.ts 的 login()
    const response = await login({ usernameOrEmail, password })

    // 2. 存到全局 store
    const { user, token } = response.data
    setAuth(user, token)
    localStorage.setItem('auth-token', token)

    // 3. 跳转首页
    navigate('/')
  }

  return <Form onFinish={handleSubmit}>...</Form>
}
```

**调用 services/auth.ts**:
```ts
export async function login(data) {
  const response = await apiClient.post('/auth/login', data)
  return response.data
}
```

**apiClient.ts 拦截器自动加 Token** + 失败重试:
```ts
apiClient.interceptors.response.use(response => response, async (error) => {
  if (error.response?.status === 401 && !error.config._retried) {
    // 用 refreshToken 续期
    // ...
  }
})
```

→ **请求真正发送到**: `POST http://localhost:3000/api/auth/login`

---

### Step 2:请求到达后端

**配置**:
```
Nginx (端口 443)
  → /api/ 转发
  → 转到 localhost:3000
```

**Express 全局中间件** [backend/src/app.js]:
```
helmet()          → 加安全头
cors()            → 处理跨域
morgan()          → 打印日志
express.json()    → 解析 JSON body
                  → 进入 api 路由
                  → /api 匹配后 /auth 匹配后 /login 匹配
                  → 进入 authRoutes.post('/login', validate, login)
```

**auth.routes.js**:
```js
router.post('/login', authLimiter, validate(loginSchema), authController.login)
```

按顺序:
1. `authLimiter` — 每分钟最多 5 次,太多就 429
2. `validate(loginSchema)` — Joi 检查 body 格式,失败返回 400
3. `authController.login` — 调用 controller

---

### Step 3:controller 层

```js
// backend/src/controllers/auth.controller.js
async function login(req, res, next) {
  try {
    const { usernameOrEmail, password } = req.body

    const result = await authService.login(usernameOrEmail, password)
    return ApiResponse.success(res, {
      user: result.user,
      token: result.token,
      refreshToken: result.refreshToken,
    })
  } catch (error) {
    if (error.code === 'INVALID_CREDENTIALS') {
      return ApiResponse.unauthorized(res, error.message)
    }
    next(error)
  }
}
```

→ 调用 `authService.login()`

---

### Step 4:service 层(数据库操作)

```js
// backend/src/services/auth.service.js
async login(usernameOrEmail, password) {
  // 1. 找用户
  const user = await prisma.user.findFirst({
    where: usernameOrEmail.includes('@')
      ? { email: usernameOrEmail }
      : { username: usernameOrEmail },
  })

  if (!user) throw { code: 'INVALID_CREDENTIALS', ... }

  // 2. 验证密码
  const ok = await bcrypt.compare(password, user.password)
  if (!ok) throw { code: 'INVALID_CREDENTIALS', ... }

  // 3. 生成 JWT
  const token = generateToken(user.id)
  const refreshToken = generateRefreshToken(user.id)

  return { user: ..., token, refreshToken }
}
```

→ 涉及到 `prisma`、`bcrypt`、`jsonwebtoken`,最终返回 token

---

### Step 5:数据格式化返回

```
res.json(...) → axios 拦截器处理 → React 更新 state → 跳转到首页
```

最终统一格式:`{ success: true, data: {...}, message: '操作成功' }`

### 3.1 完整流程图

```
浏览器
  Login.handleSubmit()
    → services/auth.ts: login()
      → apiClient.post('/api/auth/login', ...)
        ↓
Nginx (80/443)
  → 转发到 /api/ → 127.0.0.1:3000
        ↓
Express (3000)
  helmet → cors → morgan → express.json()
  → /api → /auth → POST /login
    → authLimiter (限流)
    → validate(loginSchema) (Joi 校验)
    → authController.login
      → authService.login
        → prisma.user.findFirst (查数据库)

        → jwt.sign (生成 Token)

        ↓
返回 JSON 给浏览器
        ↓
React useAuthStore 更新 → 跳转到首页
```

## 4. 实战:看任意一个组件的步骤

**例子:** `frontend/src/pages/Blog/BlogList.tsx`

```tsx
// 第一眼:看到这些 import
import { Row, Col, Card, Input, Empty, Spin, Select, Tag } from 'antd'   // 1) UI 组件
import { SearchOutlined } from '@ant-design/icons'                       // 2) 图标

import PostCard from '../../components/blog/PostCard'                    // 4) 文章卡片
import { getPosts } from '../../services/post'                          // 5) API
import { getCategories } from '../../services/category'                  //    API

// 第二眼:看 props 和 state
function BlogList() {
  const [searchParams, setSearchParams] = useSearchParams()           // URL 参数
  const page = Number(searchParams.get('page') ?? '1')
  const [posts, setPosts] = useState<Post[]>([])                     // 数据 state
  const [categories, setCategories] = useState<Category[]>([])        // 分类 state

  // 第三眼:看 useEffect(知道它在挂载时干啥)
  useEffect(() => {
    getCategories().then(res => setCategories(res.data || []))      // 拿分类
  }, [])

  useEffect(() => {
    // 拿到所有筛选条件,调接口拿文章列表
    getPosts({
      page, limit: 9,
      search, categorySlug,
    }).then(res => {
      if (res.success && res.data) {
        setPosts(res.data.posts)
        setTotal(res.data.pagination.total)
      }
    })
  }, [page, search, categorySlug])

  // 第四眼:看 UI 部分(返回 JSX)
  return (
    <AppLayout selectedKey="blogs-view">
      <Input.Search onChange={...} />
      <Row>
        {posts.map(p => <Col><PostCard post={p} /></Col>)}

    </AppLayout>
  )
}
```

**读懂之后你会知道**:

## 6. 数据流一览(全栈)

```
┌────────────────┐   HTTP/JSON    ┌────────────────┐
│     前端        │ ─────────────→ │    后端 API     │
│                │ ←───────────── │                │
│  - React       │                │  - Express     │
│  - TypeScript  │                │  - Prisma ORM  │
│  - Zustand     │                │  - Service 层  │
│  - Axios       │                │                │
└────────────────┘                └────────┬───────┘
                                           │
                                           ↓
                                   ┌────────────────┐
                                   │   PostgreSQL   │
                                   │   数据库        │
                                   └────────────────┘
```

**手把手读流程**:
1. **数据怎么来?**:用户操作 → 组件处理 → services 调 → apiClient 发 → 后端
2. **数据怎么存?**:后端 req → controller → service → Prisma 写入数据库
3. **数据怎么显示?**:数据库 → Prisma 读出 → service 格式化 → controller → res 返 JSON → 前端 → component

## 7. 给项目加功能的标准流程

**例子:加一个"文章收藏"功能**

### Step 1:改 schema
```prisma
// prisma/schema.prisma
model Favorite {
  id        Int      @id @default(autoincrement())
  userId    Int
  postId    Int
  createdAt DateTime @default(now())

  user      User     @relation(fields: [userId], references: [id])
  post      Post     @relation(fields: [postId], references: [id])

  @@unique([userId, postId])
}
```

### Step 2:生成迁移
```bash
cd backend && npx prisma migrate dev --name add_favorites
```

### Step 3:加后端 API

```js
// backend/src/routes/favorite.routes.js
router.post('/', authenticate, async (req, res) => {
  await prisma.favorite.create({
    data: { userId: req.userId, postId: req.body.postId }
  })
  res.json({ success: true })
})

router.delete('/:postId', authenticate, async (req, res) => {
  await prisma.favorite.deleteMany({
    where: { userId: req.userId, postId: parseInt(req.params.postId) }
  })
  res.json({ success: true })
})

router.get('/my', authenticate, async (req, res) => {
  const list = await prisma.favorite.findMany({
    where: { userId: req.userId },
    include: { post: true }
  })
  res.json({ success: true, data: list })
})

module.exports = router
```

挂载到主路由:
```js
// backend/src/routes/index.js
const favoriteRoutes = require('./favorite.routes')
router.use('/favorites', favoriteRoutes)
```

### Step 4:加前端 Service

```ts
// frontend/src/services/favorite.ts
import apiClient from './apiClient'

export async function toggleFavorite(postId: number) {
  return apiClient.post('/favorites', { postId })
}

export async function getMyFavorites() {
  return apiClient.get('/favorites/my')
}
```

### Step 5:在页面加按钮


## 8. Bug 调试速查

### 8.1 启动报错

| 错误 | 可能原因 |
|------|----------|
| `Cannot find module 'express'` | 没 `npm install` |
| `EADDRINUSE :::3000` | 端口被占用 |
| `Error: connect ECONNREFUSED 5432` | 数据库没启动 |
| `JWT_SECRET...长度` | 生产环境密钥太短 |

### 8.2 接口报错

| 错误 | 看哪 |
|------|------|
| `404 Not Found` | 路由路径写错、忘挂载到 /api |
| `400 Bad Request` | Joi 校验失败,看请求 payload |
| `401 Unauthorized` | Token 没传 / 过期 / 无效 |
| `403 Forbidden` | 权限不够 |
| `500 Server Error` | 看 `pm2 logs` 或终端报错堆栈 |

### 8.3 前端报错

| 错误 | 看哪 |
|------|------|
| `Cannot read property 'X' of undefined` | 数据还没加载就用,加 `?.` |
| `Network Error` | 后端没启 / 跨域 |
| 白屏 | F12 Console 看报错 |
