## 💡 学习方法建议

1. **不要一口气看完** — 每节之间动手敲代码
2. **对照着风迹集代码看** — 每个知识点都标注了在本项目哪里出现
3. **用浏览器开发者工具** — 这是最快的学习方式
4. **遇到不懂的就查** — 编程是"查字典"的能力,不是"记忆"的能力
5. **必装工具**:

```
编辑器:VSCode(免费)
命令行:Windows Terminal + Git Bash
浏览器:Chrome 或 Edge(带 DevTools)
Node.js: v18 LTS
Git:最新版
```

## 🎯 每个阶段的学习目标

### 阶段 1:计算机基础
**你能学到**:什么是程序、文件、进程、网络

### 阶段 2:Web 基础
**你能学到**:浏览器访问网站时发生了什么、HTTP 是什么

### 阶段 3:JavaScript
**你能学到**:本项目 80% 的代码语言

### 阶段 4:Node.js + 后端
**你能学到**:本项目 `backend/` 目录的所有内容

### 阶段 5:TypeScript
**你能学到**:本项目 `frontend/src/**/*.tsx` 的类型注解

### 阶段 6:React
**你能学到**:本项目所有页面是怎么搭建的

### 阶段 7:数据库
**你能学到**:本项目 `prisma/schema.prisma` 在做什么

### 阶段 8:读懂风迹集
**你能学到**:把上面所有知识点串起来,看懂这个项目

### 阶段 9:二次开发
**你能学到**:改 bug、加新功能、改样式
