---

## 1. 什么是程序?

**程序** = 一组**指令**,告诉计算机"做什么、怎么做"

```
你写代码(一堆文字)
  ↓
程序帮你翻译成计算机能懂的语言(二进制 0101)
  ↓
计算机执行
```

**类比**:你可以把代码想象成菜谱,计算机是厨师。

## 2. 关键概念

### 2.1 文件和文件夹

```
my_website/              ← 文件夹(也叫目录)
├── backend/             ← 子文件夹
│   ├── package.json     ← 文件
│   └── src/
│       └── server.js    ← 文件
└── README.md            ← 文件
```

**Windows 用户**:用 `资源管理器` 查看
**Mac 用户**:用 `访达`
**Linux 用户**:用命令行 `ls`

### 2.2 后缀名

后缀名告诉操作系统文件类型:

| 后缀 | 是什么 |
|------|--------|
| `.txt` | 纯文本,记事本能打开 |
| `.md` | Markdown,文本格式 |
| `.js` | JavaScript 代码 |
| `.ts` | TypeScript 代码 |
| `.json` | 数据配置文件 |
| `.png`/`.jpg` | 图片 |
| `.pdf` | PDF 文档 |

风迹集项目有 `.js` `.ts` `.tsx` `.json` `.md` 几种。

### 2.3 进程和线程

- **进程**:一个正在运行的程序,有自己的内存
- **线程**:一个进程可以同时做几件事(比如边听歌边打字)

本项目后端 `node index.js` 启动后,会生成**一个 Node.js 进程**。
PM2 可以启动**多个进程**做负载均衡。

### 2.4 端口(Port)

一台电脑有 65536 个端口,每个端口号 0~65535。
不同服务开在不同端口上,互不干扰。

| 端口 | 本项目 |
|------|--------|
| 3000 | Node.js 后端 |
| 5173 | Vite 开发服务器 |
| 5432 | PostgreSQL |
| 80 | HTTP |
| 443 | HTTPS |

## 3. 客户端 vs 服务端

```
┌─────────────────┐        网络         ┌─────────────────┐
│  客户端(浏览器)   │  ←————————→  │   服务端(服务器)   │
│  你看到的界面     │                   │   提供数据/逻辑   │
│  - React 代码    │                   │   - Node.js 代码  │
│  - HTML/CSS      │                   │   - 访问数据库   │
└─────────────────┘                   └─────────────────┘
```

风迹集是**前后端分离**架构:
- **前端**:你打开浏览器看到的页面,在你电脑/手机上运行
- **后端**:在服务器上运行,提供数据和业务逻辑

## 4. 网络基础

### 4.1 IP 地址

每个联网的设备都有一个 IP,比如 `192.168.1.100`。
本地测试用 `127.0.0.1` 或 `localhost`(都指向你自己电脑)。

### 4.2 域名

人类记不住 IP,所以用域名:`github.com` = `140.82.112.4`

### 4.3 什么是 HTTP?

**HTTP** = 浏览器和服务端"说话"的语言。

```
浏览器 → GET https://your-blog.com/api/posts → 服务器
服务器 → 返回 JSON 数据                       ← 浏览器
```

**常见动词**:
- `GET` — 获取数据(查)
- `POST` — 创建数据(加)
- `PUT` — 更新数据(改)
- `DELETE` — 删除数据(删)

## 5. 本项目的"运行方式"

```
你的电脑(开发时):
  ┌─────────────────────────────────────────┐
  │  浏览器 访问 http://localhost:5173          │
  │       ↓                                  │
  │  Vite 开发服务器(端口 5173)                │

  │       ↓                                  │
  │  PostgreSQL(端口 5432)                    │

  ┌─────────────────────────────────────────┐

  │       ↓                                  │
  │  Nginx(端口 443,HTTPS)                    │
  │       ↓                                  │
  │  Node.js 后端(端口 3000,本地)              │
  │       ↓                                  │
  │  PostgreSQL(端口 5432,本地)               │
  └─────────────────────────────────────────┘
```

## 6. 必装工具

### 6.1 Node.js

```
下载地址:https://nodejs.org
选 LTS 版本(推荐 18 或 20)

安装后打开命令行验证:
  node -v   → v18.x.x
  npm -v    → 9.x.x
```

**Node.js**:让 JavaScript 可以脱离浏览器、在服务器上跑。

**npm**:Node.js 的包管理器,用来下载第三方库(类似应用商店)。

### 6.2 Git

```
下载地址:https://git-scm.com/
```

**Git**:代码版本控制工具,记录每次修改,可以回滚。

### 6.3 VSCode

```
下载地址:https://code.visualstudio.com/
```

**VSCode**:免费代码编辑器,本项目用这个写代码。

推荐装这些扩展:
- ESLint — 检查代码错误
- Prettier — 自动格式化代码
- GitLens — 增强 Git 功能
- Chinese Language Pack — 中文界面

## 7. 关键术语速查表

| 术语 | 通俗解释 |
|------|----------|
| API | 别人写的、你按规则调用一段功能(如地图 API) |
| HTTP | 浏览器和服务端的通信协议 |
| JSON | 一种数据格式,长得像 JS 对象 |
| Token | 用户登录后的"通行证" |
| Cookie | 浏览器存的小数据,可用来记登录状态 |
| LocalStorage | 浏览器存的本地数据,关浏览器还在 |
| Session | 服务端记的"一次性会话状态" |
| Deployment | 把代码部署到服务器上跑 |
| Domain | 你的网站地址(如 fengjiji.com) |
| SSL/HTTPS | 让网站更安全的小绿锁 |
