# 风迹集 — 数据库设计文档

> 版本：v1.0 | 更新日期：2026-06-30
> 数据库：PostgreSQL 16 | ORM：Prisma 5

---

## 1. ER 图（文字版）

```
users (1) ─────< posts (N) ─────< post_tags (N) >──── tags (N)
  │                                                  │
  │              categories (1) ─────< posts (N)     │
  │                                                   │
  ├────< projects (N) ────< stages (N) ────< tasks (N)
  │
  ├────< check_ins (N)
  │
  ├────< invite_codes_created (N)
  │
  └────< invite_code_used (1)

posts (1) ────< post_likes (N)    // visitorId 去重
posts (1) ────< post_views (N)    // visitorId + 30min 去重
```

## 2. 表结构详述

### 2.1 users（用户）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | `SERIAL` | PK | 自增主键 |
| username | `VARCHAR(255)` | UNIQUE, NOT NULL | 用户名 |
| email | `VARCHAR(255)` | UNIQUE, NOT NULL | 邮箱 |
| password | `VARCHAR(255)` | NOT NULL | bcrypt 哈希 |
| nickname | `VARCHAR(255)` | NULLABLE | 显示昵称 |
| avatar | `VARCHAR(500)` | NULLABLE | 头像 URL |
| bio | `TEXT` | NULLABLE | 个人简介 |
| role | `VARCHAR(50)` | DEFAULT 'admin' | 角色：admin / visitor |
| created_at | `TIMESTAMP` | DEFAULT now() | — |
| updated_at | `TIMESTAMP` | auto | — |

**索引**：`username` (UNIQUE)、`email` (UNIQUE)

---

### 2.2 posts（文章）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | `SERIAL` | PK | — |
| title | `VARCHAR(255)` | NOT NULL | 文章标题 |
| slug | `VARCHAR(255)` | UNIQUE, NOT NULL | URL 友好标识 |
| summary | `TEXT` | NULLABLE | 摘要 |
| content | `TEXT` | NOT NULL | Markdown 正文 |
| cover_image | `VARCHAR(500)` | NULLABLE | 封面图 URL |
| view_count | `INTEGER` | DEFAULT 0 | 阅读量 |
| like_count | `INTEGER` | DEFAULT 0 | 点赞数 |
| status | `VARCHAR(50)` | DEFAULT 'draft' | draft / published |
| author_id | `INTEGER` | FK → users.id, NOT NULL | 作者 |
| category_id | `INTEGER` | FK → categories.id, NULLABLE | 分类 |
| project_id | `INTEGER` | FK → projects.id, NULLABLE | 关联项目 |
| is_deleted | `BOOLEAN` | DEFAULT false | 软删除标记 |
| published_at | `TIMESTAMP` | NULLABLE | 发布时间 |
| created_at | `TIMESTAMP` | DEFAULT now() | — |
| updated_at | `TIMESTAMP` | auto | — |

**索引**：
- `slug` (UNIQUE)
- `author_id` (FK)
- `category_id` (FK)
- `project_id` (FK)
- `(status, is_deleted, created_at)` — 列表查询复合索引
- `(author_id, is_deleted)` — 用户文章查询

---

### 2.3 categories（分类）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|

| slug | `VARCHAR(255)` | UNIQUE, NOT NULL | URL 标识 |
| description | `TEXT` | NULLABLE | 描述 |
| sort_order | `INTEGER` | DEFAULT 0 | 排序权重 |
| created_at | `TIMESTAMP` | DEFAULT now() | — |

---

### 2.4 tags（标签）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | `SERIAL` | PK | — |
| name | `VARCHAR(255)` | UNIQUE, NOT NULL | 标签名称 |
| slug | `VARCHAR(255)` | UNIQUE, NOT NULL | URL 标识 |
| created_at | `TIMESTAMP` | DEFAULT now() | — |

---

### 2.5 post_tags（文章-标签关联）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| post_id | `INTEGER` | FK → posts.id, CASCADE | 文章 ID |
| tag_id | `INTEGER` | FK → tags.id, CASCADE | 标签 ID |

**索引**：复合主键 `(post_id, tag_id)`

---

### 2.6 post_likes（文章点赞）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| post_id | `INTEGER` | FK → posts.id, CASCADE | 文章 ID |
| visitor_id | `VARCHAR(64)` | NOT NULL | 访客 ID（前端生成） |
| created_at | `TIMESTAMP` | DEFAULT now() | — |

**索引**：复合主键 `(post_id, visitor_id)`

> 设计意图：visitor_id 由前端生成并持久化到 localStorage，无需登录即可点赞。同一访客对同一篇文章只能点赞一次，再次点击取消。

---

### 2.7 post_views（文章浏览记录）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | `SERIAL` | PK | — |
| post_id | `INTEGER` | FK → posts.id, CASCADE | 文章 ID |
| visitor_id | `VARCHAR(64)` | NOT NULL | 访客 ID |
| created_at | `TIMESTAMP` | DEFAULT now() | — |

**索引**：`(post_id, visitor_id, created_at)` — 30 分钟去重查询

> 设计意图：同访客 30 分钟内浏览同一篇文章只计一次阅读量。`post_views` 表负责去重逻辑，`posts.view_count` 作为冗余计数避免频繁 count。

---

### 2.8 projects（项目）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | `SERIAL` | PK | — |
| name | `VARCHAR(255)` | NOT NULL | 项目名称 |
| description | `TEXT` | NULLABLE | 描述 |
| tech_stack | `TEXT` | NULLABLE | JSON 数组 `["React","Node.js"]` |
| code_url | `VARCHAR(500)` | NULLABLE | 代码仓库地址 |
| demo_url | `VARCHAR(500)` | NULLABLE | 演示地址 |
| status | `VARCHAR(50)` | DEFAULT 'planning' | planning / in_progress / completed |
| completion_rate | `INTEGER` | DEFAULT 0 | 0-100 |
| sort_order | `INTEGER` | DEFAULT 0 | 排序 |
| is_public | `BOOLEAN` | DEFAULT true | 是否公开 |
| author_id | `INTEGER` | FK → users.id, NOT NULL | 创建者 |
| start_date | `DATE` | NULLABLE | 开始日期 |
| expected_end_date | `DATE` | NULLABLE | 预期结束 |
| buffer_days | `INTEGER` | DEFAULT 0 | 缓冲天数 |
| plan | `TEXT` | NULLABLE | JSON 数组 `[{ what, time?, weight? }]` |
| completed_at | `TIMESTAMP` | NULLABLE | 实际完成时间 |
| created_at | `TIMESTAMP` | DEFAULT now() | — |
| updated_at | `TIMESTAMP` | auto | — |

**索引**：`author_id` (FK)、`(status, is_public)`

> 设计决策：`tech_stack` 和 `plan` 使用 JSON 字符串存储而非关联表，因为技术栈和计划任务是项目属性的内聚部分，单独建表增加复杂度且查询频率低。

## 3. 索引策略总结

| 表 | 索引 | 用途 |
|----|------|------|
| posts | `(status, is_deleted, created_at DESC)` | 前台博客列表（已发布、未删除、按时间排序） |
| posts | `(author_id, is_deleted)` | 后台文章管理 |
| post_likes | `(post_id, visitor_id)` PK | 点赞去重 + 状态查询 |
| post_views | `(post_id, visitor_id, created_at)` | 30 分钟去重查询 |
| check_ins | `(user_id, date)` UNIQUE | 每日签到约束 |

## 4. 迁移管理

```bash
# 开发环境：创建迁移
npx prisma migrate dev --name 描述

# 开发环境：重置数据库（会丢失数据）
npx prisma migrate reset

# 生产环境：应用迁移
npx prisma migrate deploy

# 生成 Client（迁移后必须执行）
npx prisma generate

# 可视化数据库
npx prisma studio
```

## 5. 数据字典约定

| 约定 | 说明 |
|------|------|
| 表名 | 下划线复数 → Prisma `@@map` 映射 |
| 字段名 | Prisma 端 camelCase、数据库端 snake_case |
| 时间字段 | `created_at` / `updated_at` 统一命名 |
| 软删除 | 统一用 `is_deleted` 布尔字段 |
| JSON 字段 | 数据库存 TEXT，应用层序列化/反序列化 |
| 外键 | 统一 `xxx_id` 命名 |
