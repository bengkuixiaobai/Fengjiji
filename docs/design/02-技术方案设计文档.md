## 2. 技术选型理由

| 选型 | 当前方案 | 备选方案 | 选择理由 |
|------|----------|----------|----------|
| **后端框架** | Express 4 | Fastify / Koa | 生态最成熟、中间件丰富、社区资源多。个人项目不需要 Fastify 的极致性能 |
| **ORM** | Prisma 5 | TypeORM / Drizzle | 类型安全最佳、迁移工具链完善、schema-first 设计清晰 |
| **数据库** | PostgreSQL 16 | MySQL / SQLite | Postgres 的全文搜索、JSON 支持、索引能力更适合<br>博客内容管理场景。个人项目也用得起单机 PG |
| **前端框架** | React 18 | Vue 3 / Svelte | React 生态最成熟、Ant Design 原生支持、TS 支持好 |
| **构建工具** | Vite 5 | Webpack / Turbopack | 开发服务器秒启动、HMR 极快、Rollup 构建产物小 |
| **UI 库** | Ant Design 5 | MUI / shadcn/ui | 组件丰富度最高、中后台场景首选、主题系统完善 |
| **状态管理** | Zustand | Redux Toolkit / Jotai | API 最简洁、无 boilerplate、persist middleware 开箱即用 |
| **认证** | JWT (access + refresh) | Session / OAuth | 前后端分离架构下 JWT 天然适配、无状态服务端 |
| **数据校验** | Joi | Zod / Yup | Node.js 生态最成熟、Express 集成友好 |
| **进程管理** | PM2 | Docker / systemd | 轻量级、配置简单、日志轮转/自动重启开箱即用 |

## 4. 关键数据流

### 4.1 用户认证流程

```
登录请求 → Joi 校验 → authController.login → authService.login
  → bcrypt.compare(password, hash)
  → jwt.sign({ userId }) → 返回 { token, refreshToken, user }

每次 API 请求：
  → 请求拦截器注入 Authorization: Bearer <token>
  → auth.middleware 验证 JWT
  → 将 userId 挂载到 req.userId

Token 过期：
  → 响应 401 → apiClient 拦截器捕获
  → POST /auth/refresh { refreshToken }
  → 获取新 token → 重试原请求
  → 刷新失败 → 清除 token → 跳转登录页
```

### 4.2 阅读量记录流程

```
GET /posts/:id → getPostById
  → 返回文章内容（阅读量 +1 直接写回数据库）

POST /posts/:id/view → recordView
  → 接收 X-Visitor-Id（前端生成的持久化 ID）
  → 查询 30 分钟内是否有同访客记录
  → 无重复 → post_views 表插入一条记录
  → posts.viewCount += 1
```

### 4.3 点赞切换流程

```
POST /posts/:id/like/toggle → toggleLike
  → 接收 X-Visitor-Id
  → 查询 post_likes 表是否存在
  → 存在 → 删除记录 + likeCount - 1 → 返回 liked: false
  → 不存在 → 创建记录 + likeCount + 1 → 返回 liked: true
```

## 5. 网络安全架构

```
用户 → HTTPS (TLS 1.3) → Nginx
  ├── 速率限制（Nginx 层 + Express 层双层防护）
  ├── 请求体限制（1MB）
  ├── 安全响应头（Helmet）
  └── CORS 白名单（生产环境限定域名）
```

## 6. 部署拓扑

```
生产环境（最小配置）:
  1台云服务器 (1核1GB/20GB)
  ├── Nginx (80/443) ← 面向公网
  ├── PM2 → Node.js (3000) ← 仅本地
  └── PostgreSQL (5432) ← 仅本地

可选扩展:
  数据库分离 → 云数据库 RDS
  静态资源 CDN → 对象存储 + CDN
  负载均衡 → 多 Node.js 实例
```

## 7. 安全措施

| 维度 | 措施 |
|------|------|
| 传输层 | Nginx 强制 HTTPS、TLS 1.3、HSTS |
| 应用层 | Helmet 安全头、CORS 白名单、请求体 1MB 限制 |
| 认证层 | JWT 强密钥、refresh token 轮换、bcrypt 哈希 |
| 速率限制 | express-rate-limit（登录/注册 5次/分钟） |
| 文件上传 | 扩展名 + MIME 魔数双重校验、5MB 限制 |
| 注入防护 | Prisma ORM 参数化查询 |
| XSS 防护 | react-markdown 默认不渲染 HTML |
| CSRF 防护 | JWT Bearer 天然免疫 |
| 运维层 | PM2 自动重启、日志轮转、备份策略 |
