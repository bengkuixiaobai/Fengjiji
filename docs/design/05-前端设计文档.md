## 2. 状态管理设计

### 2.1 Store 结构

```
authStore (persisted to localStorage)
├── user: User | null           // 当前用户
├── token: string | null        // Access Token
├── refreshToken: string | null // Refresh Token
├── isAuthenticated: boolean
├── isLoading: boolean
├── error: string | null
└── methods: login(), logout(), setLoading(), setError(), clearError()

themeStore (persisted to localStorage)
├── isDarkMode: boolean
└── methods: toggleTheme(), setDarkMode()
```

### 2.2 数据流策略

```
页面组件
  ↓ (调用 Service 函数)
Services Layer (post.ts / project.ts / auth.ts ...)
  ↓
apiClient (axios 单例)
  ├── 请求拦截: 注入 Authorization + X-Visitor-Id
  ├── 响应拦截: 401 → refreshToken 续期 / 失败 → 跳转登录
  └── VITE_USE_MOCK 开关 → mock handlers 或真实 API
```

- 大多数页面数据是**请求时获取**（不在 Store 中持久化）
- `authStore` 和 `themeStore` 是唯二使用 Zustand `persist` 的 Store
- localStorage 存储的**键名约定**：

| Key | 用途 |
|-----|------|
| `auth-storage` | Zustand persist: 用户登录态 |
| `theme-storage` | Zustand persist: 主题偏好 |
| `auth-token` | Access Token（apiClient 直接读取） |
| `auth-refresh-token` | Refresh Token |
| `visitor-id` | 匿名访客 ID（点赞/阅读量去重） |
| `user-avatar-override` | 用户自定义头像（base64） |
| `greeting-bg` | 首页问候背景设置 |
| `blog-sort` | 博客排序偏好 |
| `md-fontsize` | Markdown 编辑器字号 |

## 5. 权限控制

### 5.1 路由级

所有后台管理页包裹 `ProtectedRoute` 组件：

```tsx
function ProtectedRoute({ children }) {
  const isAuthenticated = useAuthStore((state) => state.isAuthenticated)
  if (!isAuthenticated) return <Navigate to="/login" replace />
  return <>{children}</>
}
```

### 5.2 操作级

后端根据 JWT 中的 `userId` 校验操作权限（仅作者可编辑/删除自己的内容）。

### 5.3 菜单/按钮级

目前未实现角色区分（仅有 `admin` 和 `visitor`），后续可扩展：

```tsx
// 权限 Hook（示例）
function usePermission() {
  const role = useAuthStore(s => s.user?.role)
  return {
    canManage: role === 'admin',
    canDelete: role === 'admin',
  }
}
```

## 6. 主题系统

### 6.1 实现方式

- **CSS 变量**：`:root`（深色默认）+ `[data-theme='light']` 覆盖
- **Ant Design**：`ConfigProvider` + `theme.darkAlgorithm / theme.defaultAlgorithm`
- **存储**：`theme-storage` localStorage key

### 6.2 主题变量

```css
--text-color          /* 主文字 */
--secondary-text      /* 次要文字 */
--muted-text          /* 弱化文字 */
--card-bg             /* 卡片背景 */
--card-border         /* 卡片边框 */
--page-bg             /* 页面渐变背景 */
--accent-start        /* 主色起始 */
--accent-end          /* 主色终点 */
--accent-gradient     /* 主色渐变 */
--btn-primary-bg      /* 按钮背景 */
--shadow-sm/md/lg     /* 阴影层级 */
```

### 6.3 切换机制

```tsx
// themeStore.ts
setDarkMode: (dark) => {
  document.documentElement.setAttribute('data-theme', dark ? 'dark' : 'light')
  set({ isDarkMode: dark })
}
```

深色模式为默认（store 初始化时同时设置 `data-theme` 属性）。

## 7. 性能优化措施

### 7.1 已实施

| 措施 | 说明 |
|------|------|
| 路由级 Lazy Loading | 每个页面使用 `React.lazy()` + `Suspense` |
| 代码分包 | Vite `rollupOptions.output.manualChunks` 拆出 react-vendor / antd-vendor / editor 等 |
| 请求并行 | 首页同时请求 5 个独立 API（`Promise.all`） |
| Mock 延迟控制 | dev 模式 150ms 模拟延迟，prod 模式 0ms |
| CSS 变量主题切换 | 不触发 React 重渲染，仅 CSS 过渡动画 |
| `useMemo` + `useCallback` | 避免不必要的重渲染 |
| 稳定引用 | 主题对象 `useMemo` 缓存，避免 Ant Design css-in-js 重建 |

### 7.2 规划中

| 措施 | 优先级 | 预期效果 |
|------|--------|----------|
| 图片懒加载 | P2 | 减少首屏请求数 |
| 数据预取（路由级） | P2 | 跳转后不白屏 |
| 无限滚动（博客列表） | P3 | 替代分页按钮 |
| Service Worker 缓存 | P3 | 离线访问 + 更快回访 |
