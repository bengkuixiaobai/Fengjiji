# 风迹集 — 环境变量与配置参考

> 所有环境变量的说明和推荐值

---

## 后端环境变量

配置文件位置：`backend/.env`

| 变量名 | 必填 | 默认值 | 说明 |
|--------|------|--------|------|
| `DATABASE_URL` | ✅ | — | PostgreSQL 连接字符串 |
| `JWT_SECRET` | ✅ | `dev-only-secret-...` | JWT 签名密钥（生产环境强制 32+ 字符） |
| `JWT_EXPIRES_IN` | 否 | `15m` | Access Token 有效期（如 `1h`、`7d`） |
| `JWT_REFRESH_EXPIRES_IN` | 否 | `7d` | Refresh Token 有效期 |
| `PORT` | 否 | `3000` | 后端监听端口 |
| `NODE_ENV` | 否 | `development` | 运行环境（`production` / `development`） |
| `CORS_ORIGIN` | 否 | dev: `*`, prod: `false` | 允许跨域来源（逗号分隔） |

### 示例

```env
DATABASE_URL="postgresql://fengjiji:StrongPassword123@localhost:5432/fengjiji?schema=public"
JWT_SECRET="a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4e5f6a1b2"
JWT_EXPIRES_IN="1h"
JWT_REFRESH_EXPIRES_IN="7d"
PORT=3000
NODE_ENV=production
CORS_ORIGIN=https://myblog.com,https://www.myblog.com
```

### 生成 JWT_SECRET

```bash
# 推荐方式
openssl rand -hex 32
# 输出示例: a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4e5f6a1b2

# 也可用
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

### DATABASE_URL 格式说明

```
postgresql://用户名:密码@主机:端口/数据库名?schema=public
```

| 部分 | 说明 | 示例 |
|------|------|------|
| `用户名` | 数据库用户 | `fengjiji` |
| `密码` | 数据库密码 | `YourPassword123` |
| `主机` | 数据库地址 | `localhost` 或云数据库地址 |
| `端口` | PostgreSQL 端口 | `5432`（默认） |
| `数据库名` | 数据库名称 | `fengjiji` |
| `schema` | 数据库 schema | `public` |

### 生产环境强制校验

生产模式下启动时，系统会检查：

1. `JWT_SECRET` 是否存在且长度 >= 32 字符
2. 如果是默认值 `default-secret-key` 会直接退出

如果不满足条件，服务会打印错误并退出：

```
❌ FATAL: 生产环境必须设置强 JWT_SECRET (至少 32 字符)
   生成方式: openssl rand -hex 32
```

## 前端环境变量

配置文件位置：`frontend/.env`

| 变量名 | 必填 | 默认值 | 说明 |
|--------|------|--------|------|
| `VITE_API_BASE_URL` | 否 | `/api` | API 请求基础路径 |
| `VITE_USE_MOCK` | 否 | `true`（未设置时） | 是否使用 Mock 数据 |

> 生产环境必须设置 `VITE_USE_MOCK=false`，否则页面数据不会真实请求后端 API。

### 示例

```env
# 生产环境
VITE_API_BASE_URL=/api
VITE_USE_MOCK=false
```

### 构建时注入

`VITE_*` 变量在 `npm run build` 时编译进静态文件。如果使用不同的 API 地址，需要在构建时传入：

```bash
VITE_API_BASE_URL=https://api.myblog.com npm run build
```

## PM2 配置

见根目录的 [ecosystem.config.js](../ecosystem.config.js)。

关键参数：

| 参数 | 当前值 | 说明 |
|------|--------|------|
| 进程名 | `fengjiji-api` | — |
| 执行模式 | `fork` | 单进程模式 |
| 内存上限 | `500M` | 超过自动重启 |
| 日志大小上限 | `10M` | 超过自动轮转 |
| 保留日志份数 | `10` | 最多保留 10 份历史日志 |
| 自动重启 | `true` | 崩溃后自动重启（最多 10 次） |

## Nginx 配置

参考 `docs/02-环境搭建与部署指南.md` 第 6 节。

关键参数：

| 参数 | 当前值 | 说明 |
|------|--------|------|
| `client_max_body_size` | `10m` | 上传大小限制 |
| `proxy_read_timeout` | `60s` | 后端响应超时 |
| `expires` (static) | `30d` | 静态资源缓存（JS/CSS/图片） |
| `expires` (uploads) | `7d` | 上传图片缓存 |
