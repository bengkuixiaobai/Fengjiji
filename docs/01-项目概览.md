# 风迹集 — 项目概览

> 个人博客与作品集管理平台

---

## 项目定位

记录技术思考，分享项目经验，追踪项目进度。面向个人开发者的一站式博客+项目管理平台。

## 技术栈

| 层级 | 技术 | 版本 |
|------|------|------|
| 前端框架 | React | 18.x |
| 前端语言 | TypeScript | 5.x |
| 构建工具 | Vite | 5.x |
| UI 组件库 | Ant Design | 5.x |
| 状态管理 | Zustand | 4.x |
| 后端框架 | Express | 4.x |
| ORM | Prisma | 5.x |
| 数据库 | PostgreSQL | 14+ |
| 认证 | JWT (access + refresh token) | — |

## 数据模型

- **User** — 用户（管理员/访客，支持注册和邀请码）
- **Post** — 文章（Markdown 内容，支持分类/标签/项目关联）
- **Category** — 文章分类
- **Tag** — 文章标签（多对多）
- **Project** — 项目管理（含计划任务、时间线）
- **Stage** — 项目阶段
- **Task** — 阶段任务
- **PostLike** — 文章点赞（访客 ID 去重）
- **PostView** — 文章浏览记录（30 分钟内同访客不重复计数）
- **CheckIn** — 每日签到
- **InviteCode** — 注册邀请码

## 接口概览

| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| POST | `/api/auth/register` | 注册 | 公开（限流） |
| POST | `/api/auth/login` | 登录 | 公开（限流） |
| POST | `/api/auth/refresh` | 刷新 Token | 公开 |
| POST | `/api/auth/logout` | 登出 | 需登录 |
| GET | `/api/users/me` | 获取当前用户 | 需登录 |
| PUT | `/api/users/me` | 更新个人资料 | 需登录 |
| PUT | `/api/users/me/password` | 修改密码 | 需登录 |
| GET/POST | `/api/posts` | 文章列表/创建 | 列表公开/创建需登录 |
| GET/PUT/DELETE | `/api/posts/:id` | 文章详情/更新/删除 | 详情公开/其余需登录 |
| POST | `/api/posts/:id/view` | 记录阅读量 | 公开 |
| POST | `/api/posts/:id/like/toggle` | 切换点赞 | 公开 |
| GET | `/api/posts/:id/adjacent` | 上下篇导航 | 公开 |
| GET/POST | `/api/projects` | 项目列表/创建 | 列表公开/创建需登录 |
| GET/PUT/DELETE | `/api/projects/:id` | 项目详情/更新/删除 | 详情公开/其余需登录 |
| GET/POST | `/api/categories` | 分类列表/创建 | 列表公开/创建需登录 |
| DELETE | `/api/categories/:id` | 删除分类 | 需登录 |
| GET/POST | `/api/tags` | 标签列表/创建 | 列表公开/创建需登录 |
| GET | `/api/tags/:id` | 标签详情 | 公开 |
| GET/POST | `/api/checkins` | 签到记录/签到 | 需登录 |
| GET | `/api/checkins/stats` | 签到统计 | 需登录 |
| GET | `/api/stats/dashboard` | 仪表盘统计 | 需登录 |
| POST | `/api/upload` | 上传图片 | 需登录 |
| GET | `/api/health` | 健康检查 | 公开 |
