## 一、购买清单(以腾讯云轻量为例)

### 1.1 推荐配置

| 项 | 推荐值 | 说明 |
|----|--------|------|
| **节点** | 中国香港 / 新加坡 | 免备案,5 分钟开通 |
| **配置** | 4 核 4G SSD 50GB 3M | 你已确认 |

| **登录方式** | 自定义密码(临时) | 首次 SSH 用,稍后改成密钥登录 |
| **购买时长** | 先买 1 个月 | 试用 OK 后改年付(便宜 30-50%) |

### 1.2 国内大陆节点(如果要备案)

如果选中国大陆节点:
- 必须先在服务商备案系统提交资料(身份证 + 域名)
- 备案需要 7-15 个工作日
- 期间 IP 80/443 端口会被封,只能 SSH 内网 IP

> 个人博客建议**直接选香港**,免备案省事很多。

### 1.3 实名认证

购买前需要:
- 实名认证(身份证号 + 人脸识别)
- 通常 5 分钟内通过

## 二、首次登录检查清单

买到后,**做这 10 件事**:

### 2.1 验证能 SSH 登录 ✅

```bash
# Windows 用 PowerShell 或 Git Bash
# Mac/Linux 用 Terminal

ssh ubuntu@你的服务器IP
# 第一次会问 yes/no,输入 yes
# 输入密码(输入时不显示)
```

看到 `$` 提示符 = 成功。

### 2.2 切换到 root 用户(简化后续命令)

```bash
sudo -i
```

后续命令都默认 root 身份执行(本项目是个人博客,不需要细权限)。

### 2.3 修改 root 密码(强烈推荐)

```bash
passwd
# 输入新密码两次
# 复杂度建议:16 位以上,大小写+数字+符号
```

记下来!**这是以后 SSH 登录的唯一凭据**。

### 2.4 ~~修改 SSH 端口~~ ❌ 不推荐

> ⚠️ **不要改 SSH 端口!** 改端口的"安全收益"几乎为零(端口扫描 5 秒能找到),但操作失误导致完全失联的风险是 100% 真实的(本人亲历)。
>
> 真正有效的 SSH 安全措施见末尾的"第二部分 · 安全收尾"。

### 2.5 配置防火墙(只开必要端口) ✅

```bash
# 安装 UFW(如果没有)
apt install -y ufw

# 默认策略:拒绝入站、允许出站
ufw default deny incoming
ufw default allow outgoing

# 允许 SSH(默认 22 端口)
ufw allow 22/tcp

# 允许 HTTP / HTTPS(以后部署用)
ufw allow 80/tcp
ufw allow 443/tcp

# 启用
ufw enable
# 会问 yes/no,确认

# 查看状态
ufw status verbose
```

### 2.6 系统更新 + 基础工具 ✅

```bash
apt update && apt upgrade -y
apt install -y curl wget git vim ufw fail2ban unzip build-essential
```

### 2.7 设置时区(显示本地时间) ✅

```bash
# 查看当前时间
date

# 设置为东八区
timedatectl set-timezone Asia/Shanghai

# 验证
date
```

### 2.8 配置 swap(4GB 内存够用,但加 4GB swap 兜底) ✅

```bash
# 创建 4GB swap 文件
fallocate -l 4G /swapfile
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile

# 开机自动挂载
echo '/swapfile none swap sw 0 0' >> /etc/fstab

# 验证
free -h
```

应该看到 swap 行有 4G。

### 2.9 创建应用用户(后续服务用这个用户跑,不用 root)

```bash
# 创建用户
useradd -m -s /bin/bash fengjiji
passwd fengjiji
# 设置密码(记下来)

# 给 sudo 权限
usermod -aG sudo fengjiji

# 切换到该用户(后续都用它)
su - fengjiji
```

### 2.10 安装 fail2ban(防 SSH 暴力破解) ✅

```bash
systemctl enable fail2ban
systemctl start fail2ban

# 查看封禁列表
fail2ban-client status sshd
```

## 三、必做的安全收尾

### 3.1 在云厂商控制台配置安全组

进入服务器实例 → **防火墙/安全组** → 编辑规则:

| 协议 | 端口 | 来源 | 说明 |
|------|------|------|------|
| TCP | 22 | 你的 IP(可选,更安全) | SSH |
| TCP | 80 | 0.0.0.0/0 | HTTP |
| TCP | 443 | 0.0.0.0/0 | HTTPS |
| TCP | 22 | ❌ **关闭** | 老的 22 端口不用开 |

### 3.2 (可选)配置 SSH 密钥登录

密码登录方便,但**密钥登录更安全**。有精力建议配:

```bash
# 在你的电脑上(不是服务器)生成密钥
ssh-keygen -t ed25519
# 一路回车,会生成 ~/.ssh/id_ed25519 和 id_ed25519.pub

# 把公钥传到服务器
ssh-copy-id -p 22 root@你的服务器IP
# 输入密码

# 测试密钥登录
ssh -p 22 root@你的服务器IP
# 不用输密码 = 成功
```

服务器收到后,在 `/etc/ssh/sshd_config` 里改:
```
PasswordAuthentication no
```
然后 `systemctl restart sshd`。**先确认密钥能用再关密码!**
