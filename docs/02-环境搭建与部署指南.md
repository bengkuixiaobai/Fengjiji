## 1. 服务器初始化

```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装基础工具
sudo apt install -y curl wget git unzip build-essential

# 配置时区（可选）
sudo timedatectl set-timezone Asia/Shanghai

# 创建应用用户（不建议用 root 运行）
sudo useradd -m -s /bin/bash fengjiji
sudo usermod -aG sudo fengjiji
```

## 2. 安装运行时环境

### Node.js 18 LTS

```bash
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install -y nodejs

# 验证
node -v   # v18.x.x
npm -v    # 9.x.x
```

### PM2（进程管理）

```bash
sudo npm install -g pm2
pm2 --version
```

### PostgreSQL 16

```bash
# PostgreSQL 官方源（Ubuntu 22.04）
sudo sh -c 'echo "deb http://apt.postgresql.org/pub/repos/apt $(lsb_release -cs)-pgdg main" > /etc/apt/sources.list.d/pgdg.list'
curl -fsSL https://www.postgresql.org/media/keys/ACCC4CF8.asc | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/postgresql.gpg
sudo apt update
sudo apt install -y postgresql-16

# 启动
sudo systemctl enable postgresql
sudo systemctl start postgresql
```

## 3. 配置 PostgreSQL

```bash
# 切换到 postgres 用户
sudo -u postgres psql
```

在 psql 中执行：

```sql
-- 创建数据库
CREATE DATABASE fengjiji;

-- 创建专用用户（密码替换为强密码）
CREATE USER fengjiji WITH PASSWORD 'your-strong-password-here';

-- 授权
GRANT ALL PRIVILEGES ON DATABASE fengjiji TO fengjiji;
GRANT ALL ON SCHEMA public TO fengjiji;

-- 退出
\q
```

### 配置密码认证

```bash
sudo sed -i 's/local   all             all                                     peer/local   all             all                                     md5/' /etc/postgresql/16/main/pg_hba.conf
sudo systemctl restart postgresql
```

## 4. 部署后端

```bash
# 克隆项目
cd /var/www
sudo git clone <你的仓库地址> my_website
sudo chown -R fengjiji:fengjiji my_website

# 切换到应用用户
sudo -u fengjiji -i
cd /var/www/my_website/backend

# 创建环境变量文件
cat > .env << 'EOF'
# 数据库
DATABASE_URL="postgresql://fengjiji:your-strong-password-here@localhost:5432/fengjiji?schema=public"

# JWT（生产环境必须修改！用 openssl rand -hex 32 生成）
JWT_SECRET="your-64-char-hex-string-generated-by-openssl-rand-hex-32"
JWT_EXPIRES_IN="15m"
JWT_REFRESH_EXPIRES_IN="7d"

# 服务器
PORT=3000
NODE_ENV=production

# CORS（你的前端域名，多个用逗号分隔）
CORS_ORIGIN=https://your-domain.com
EOF

# 安装依赖
npm install

# 运行数据库迁移
npx prisma migrate deploy

# 生成 Prisma Client
npx prisma generate

# 初始化种子数据（管理员 + 邀请码）
node prisma/seed.js

# 启动（PM2）
pm2 start /var/www/my_website/ecosystem.config.js --env production
pm2 save
```

### 设置 PM2 开机自启

```bash
# 退出应用用户后，用 sudo 执行
sudo env PATH=$PATH:/usr/bin pm2 startup -u fengjiji --hp /home/fengjiji
```

## 6. 配置 Nginx

```bash
sudo apt install -y nginx
```

创建 `/etc/nginx/sites-available/fengjiji`：

```nginx
# 上游后端服务
upstream fengjiji_api {
    server 127.0.0.1:3000;
    keepalive 32;
}

# HTTP → HTTPS 重定向
server {
    listen 80;
    server_name your-domain.com www.your-domain.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name your-domain.com www.your-domain.com;

    # SSL（由 certbot 自动填充）
    ssl_certificate     /etc/letsencrypt/live/your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your-domain.com/privkey.pem;

    # 安全头
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;
    add_header Referrer-Policy "strict-origin-when-cross-origin" always;

    # 静态资源（前端）
    root /var/www/my_website/frontend/dist;
    index index.html;
    etag on;

    # Gzip 压缩
    gzip on;
    gzip_types text/css text/javascript application/javascript application/json image/svg+xml;
    gzip_min_length 256;

    # 上传文件大小限制
    client_max_body_size 10m;

    # API 反向代理
    location /api/ {
        proxy_pass http://fengjiji_api;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 60s;
        proxy_send_timeout 60s;

        # 禁止缓存 API 响应
        add_header Cache-Control "no-store";
    }

    # 上传文件访问
    location /uploads/ {
        proxy_pass http://fengjiji_api;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        expires 7d;
        add_header Cache-Control "public, immutable";
    }

    # SPA 路由（所有非文件请求返回 index.html）
    location / {
        try_files $uri $uri/ /index.html;

        # 静态资源缓存
        location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff2?)$ {
            expires 30d;
            add_header Cache-Control "public, immutable";
            access_log off;
        }
    }

    # 禁止访问敏感路径
    location ~ /\.git {
        deny all;
        return 404;
    }
    location ~ /node_modules {
        deny all;
        return 404;
    }
    location ~ /\.env {
        deny all;
        return 404;
    }
}
```

激活站点：

```bash
sudo ln -s /etc/nginx/sites-available/fengjiji /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t
sudo systemctl reload nginx
```

## 7. 配置 HTTPS

```bash
# 安装 certbot
sudo apt install -y certbot python3-certbot-nginx

# 获取证书（会修改 Nginx 配置）
sudo certbot --nginx -d your-domain.com -d www.your-domain.com

# 测试自动续期
sudo certbot renew --dry-run
```

## 8. 启动与验证

```bash
# 检查后端进程
pm2 list

# 检查 Nginx
sudo nginx -t

sudo systemctl status postgresql

# API 健康检查
curl https://your-domain.com/api/health

# 预期返回：
# {"success":true,"message":"服务器运行正常","timestamp":"2026-06-30T..."}
```

## 9. 部署更新流程

```bash
# 拉取最新代码
cd /var/www/my_website
git pull

# 更新后端
cd backend
npm install
npx prisma migrate deploy
npx prisma generate
pm2 restart fengjiji-api

# 更新前端
cd ../frontend
npm install
npm run build

# 重载 Nginx（如果 Nginx 配置有变化）
sudo nginx -t && sudo systemctl reload nginx
```

也可以写成一键脚本 `deploy.sh`：

```bash
#!/bin/bash
set -e
cd /var/www/my_website

git pull

cd backend
npm install --production
npx prisma migrate deploy
npx prisma generate
pm2 restart fengjiji-api

cd ../frontend
npm install
npm run build

echo "✅ 部署完成"
```

## 数据库迁移命令速查

| 命令 | 说明 |
|------|------|
| `npx prisma migrate dev` | 开发环境：创建并应用迁移 |
| `npx prisma migrate deploy` | 生产环境：应用未执行的迁移 |
| `npx prisma generate` | 生成 Prisma Client |
| `npx prisma studio` | 数据库管理 UI（仅开发环境） |
| `node prisma/seed.js` | 运行种子数据脚本 |

> `migrate deploy` 不会创建新迁移，只应用已有的。如果 schema 变了，开发机上先跑 `migrate dev` 生成迁移文件，提交到 Git，生产环境再跑 `migrate deploy`。
